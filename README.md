# Students Database CRUD API - EWB Internship

Python backend for managing student records using FastAPI + SQLite.

## Features
- Create, Read, Update, Delete students
- SQLite persistence (students.db)
- Input validation & 404 handling
- Swagger UI at /docs

## Tech Stack
Python 3.14, FastAPI, SQLAlchemy, SQLite, Uvicorn
